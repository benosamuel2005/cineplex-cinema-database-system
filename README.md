# Cineplex Cinema Database Management System

A relational database project developed using Microsoft SQL Server and T-SQL as part of my BSc (Honours) in Computing at Dublin Business School.

## Project Overview

This academic project focuses on designing and implementing a relational database for a cinema management system.

The database models cinema operations, including customers, films, screenings, bookings, tickets, concessions and orders.

## Technologies Used

- Microsoft SQL Server
- T-SQL
- Relational Database Design
- Entity Relationship Diagrams (ERD)

## Database Entities

The database design includes nine main entities:

- Customer
- Booking
- Ticket
- Showing
- Film
- Screen
- Orders
- Order Item
- Concession

## Project Files

| File | Description |
|---|---|
| `01_Create_Database.sql` | Creates the database |
| `02_Create_Tables.sql` | Defines database tables |
| `03_Insert_Data.sql` | Inserts sample records |
| `04_Stored_Procedures.sql` | Contains stored procedures |
| `05_View.sql` | Defines SQL views |

An Entity Relationship Diagram is also included in the repository to illustrate the database structure and relationships.

## Running the Project

1. Open Microsoft SQL Server Management Studio (SSMS).
2. Run `01_Create_Database.sql`.
3. Run `02_Create_Tables.sql`.
4. Run `03_Insert_Data.sql`.
5. Run `04_Stored_Procedures.sql`.
6. Run `05_View.sql`.

Review the scripts for database names and dependencies before execution.
